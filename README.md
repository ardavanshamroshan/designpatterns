# Design Patterns & SOLID

Hands-on Python tutorials for classic **design patterns** and the **SOLID** principles.

## Docs

**https://ardavanshamroshan.github.io/designpatterns/**

```bash
cd docs-site
npm install
npm run docs:dev
```

## Requirements

- Python **≥ 3.14**
- [uv](https://docs.astral.sh/uv/)

```bash
uv sync
uv run srp
```
